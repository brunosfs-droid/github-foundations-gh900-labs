# Código de conduta

Este é um espaço educacional para estudar Git e GitHub.

## Comportamento esperado
- Respeite as pessoas, inclusive diante de dúvidas básicas e opiniões divergentes.
- Faça comentários técnicos, objetivos e construtivos.
- Proteja informações pessoais e credenciais.

## Comportamento inaceitável
- Assédio, ameaças, discriminação ou ataques pessoais.
- Exposição indevida de dados privados.
- Spam ou divulgação maliciosa de conteúdos.

## Aplicação
O mantenedor poderá moderar comentários, encerrar discussões ou restringir participações que violem estas regras. Para relatar incidentes, procure o mantenedor por canal privado.

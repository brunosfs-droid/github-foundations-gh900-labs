# LAB 08 — Code Review (cenário fictício)

> **Atenção:** exercícios de revisão; os arquivos deste diretório não são consumidos por nenhuma aplicação, serviço de nuvem ou GitHub Actions. Não copiar estas configurações para ambientes reais.

## Missão
Você é o revisor de uma proposta de configuração para um serviço web fictício e um pipeline didático. Leia os dois arquivos em **Files changed** e identifique problemas de segurança, qualidade e governança.

## Tarefas
1. Registrar ao menos **dois comentários inline** no diff da PR, mencionando risco, impacto e correção sugerida.
2. Explicar por que você escolheria **Request changes**, **Comment** ou **Approve**.
3. Conferir a aba Conversation e a seção Checks.
4. Não fazer merge nem marcar Ready for review antes do checkpoint e da correção dos problemas.

## Critério de aprovação
Encontrar pelo menos três problemas relevantes, classificá-los por prioridade e sugerir medidas concretas. As respostas serão avaliadas antes de um commit de correção.

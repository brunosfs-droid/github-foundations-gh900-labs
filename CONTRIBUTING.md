# Contribuindo

Este repositório é um laboratório educacional de Git e GitHub Foundations (GH-900).

## Fluxo de contribuição
1. Crie uma branch a partir de `main` (ex.: `lab05/minha-melhoria`).
2. Faça alterações pequenas e commits descritivos.
3. Verifique se os exemplos de comandos e links estão corretos.
4. Abra uma Pull Request explicando objetivo, mudanças e como validou.
5. Revise o diff e os comentários antes de integrar à `main`.

## Convenções
- Documentação em Markdown, preferencialmente em português.
- Não envie senhas, tokens, arquivos `.env` nem dados pessoais de terceiros.
- Dúvidas e sugestões podem ser registradas como Issues.

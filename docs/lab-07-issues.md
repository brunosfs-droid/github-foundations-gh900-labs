# LAB 07 — GitHub Issues e rastreabilidade

## Objetivo
Gerenciar uma melhoria documental utilizando Issue, branch e Pull Request.

## Conceitos
- **Issue:** registra e acompanha tarefas, melhorias e problemas.
- **Label:** classifica os itens de trabalho.
- **Assignee:** indica quem está responsável pelo item.
- **Milestone:** agrupa Issues e PRs por objetivo ou entrega.
- **Pull Request:** propõe alterações em uma branch para revisão e integração.

## Fluxo hands-on
1. Criar a Issue com objetivo e critérios de aceitação.
2. Classificá-la com `documentation` e definir um assignee.
3. Criar uma branch específica a partir de `main`.
4. Registrar um commit com a documentação.
5. Abrir uma Pull Request em Draft e relacioná-la à Issue com `Closes #8`.
6. Inspecionar o diff em **Files changed**, comentários e verificações.
7. Solicitar autorização antes de fazer o merge para `main`.

## Reflexão
A Issue descreve **o que** deve ser feito; a Pull Request registra **como** a alteração será revisada e integrada.

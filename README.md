# GitHub Foundations — GH-900 Labs

Repositório educacional de estudos e laboratórios práticos para a certificação **GitHub Foundations (GH-900)**.

## Objetivos
- Praticar Git, branches, commits e sincronização de repositórios.
- Utilizar Issues, Pull Requests, revisões e GitHub Flow.
- Aprender documentação, governança e recursos de colaboração do GitHub.

## Organização dos estudos
- **Módulo 1 — Git e GitHub do zero:** LABs 01–04.
- **Módulo 2 — Administração de repositórios:** LABs 05–06.
- **Módulo 3 — Colaboração profissional:** LABs 07–09.
- **Módulo 4 — Desenvolvimento moderno:** LABs 10–12.
- **Módulo 5 — Gestão de projetos:** LABs 13–14.

O repositório pode evoluir conforme a execução dos laboratórios. A lista não significa que todos os LABs já estejam concluídos.

## Fluxo sugerido
1. Criar uma branch de trabalho a partir de `main`.
2. Alterar arquivos e registrar commits.
3. Enviar a branch ao GitHub.
4. Abrir uma PR, revisar o diff e verificar os checks.
5. Integrar as alterações após a validação.

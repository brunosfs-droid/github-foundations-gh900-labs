# Política de segurança

Este repositório contém materiais educacionais e não fornece software operacional para produção.

## Reporte de vulnerabilidades
Não divulgue credenciais ou detalhes exploráveis em Issues públicas. Se o recurso **Private vulnerability reporting** estiver habilitado no repositório, utilize-o. Caso contrário, contate o mantenedor por um canal privado antes de divulgar detalhes.

## Boas práticas
- Não comite tokens, chaves SSH privadas, senhas ou arquivos de ambiente com segredos.
- Se houver exposição de credenciais, revogue ou rotacione imediatamente as credenciais afetadas.
- O `.gitignore` não remove segredos já registrados no histórico.

## Versões suportadas
Não há versões de software lançadas; correções na documentação são tratadas na branch `main`.

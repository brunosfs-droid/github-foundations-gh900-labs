
# LAB 04 — GitHub Flavored Markdown

## Objetivo

Aprender a documentar projetos utilizando Markdown.

## Conceitos fundamentais

O **Git** é um sistema de controle de versão.

O *GitHub* é uma plataforma de colaboração baseada em Git.

### Comandos importantes

| Comando | Finalidade |
|---|---|
| `git status` | Consulta o estado do repositório |
| `git add` | Adiciona alterações ao staging |
| `git commit` | Registra alterações localmente |
| `git push` | Envia commits ao remoto |

### Exemplo no terminal

```bash
git status
git add .
git commit -m "docs: adiciona documentacao"
git push origin minha-branch
```

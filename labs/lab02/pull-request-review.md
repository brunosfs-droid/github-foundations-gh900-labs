# LAB 02 - Pull Request review

## Objetivo
Praticar revisao de alteracoes no GitHub.

## Git Commit
O comando git commit registra alterações no repositório local. Para enviar os commits ao GitHub, utilizamos git push.

## Git Push
O comando git push envia commits locais para o repositorio remoto.

## Pull Request
Permite propor e revisar alteracoes antes da integracao.


## Exemplo pratico: git commit versus git push

O comando git commit registra alteracoes no repositorio local. 

Exemplo:

git add README.md
git commit -m "docs: atualiza readme"

Ate este momento, o commit permanece local.

Para publica-lo no repositorio remoto:

git push

## Resumo

- git add: prepara as alteracoes.
- git commit: registra as alteracoes localmente.
- git push: envia commits para o repositorio remoto.
